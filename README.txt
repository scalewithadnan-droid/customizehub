CUSTOMIZE HUB STATIC WEBSITE

1. IMPORTANT: Before publishing, replace the placeholder email in about.html and privacy.html with your official company/support email.
2. Upload all files to the root of your GitHub Pages repository.
3. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch > main / root.
4. For custom domain, add customizehub.website in GitHub Pages settings. GitHub may create a CNAME file automatically.
5. Configure your domain DNS according to the exact GitHub Pages instructions shown for your repository/domain.

Pages: Home, Products, About Us, Privacy Policy, 404.
